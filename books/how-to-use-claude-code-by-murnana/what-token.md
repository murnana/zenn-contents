## トークン (token) とは

本来の英単語の意味では、商品券や引換券といった意味になります。

Claudeの場合、ユーザーのチャット内容やファイルを読み取るとき、あるいは返事をするときの一種の単位のことを指します。
よく1文字あたりトークンはいくつ、という例が挙がっていますが、これは使用するモデルや言語によって異なります。


## トークンを減らしたいのはなぜか

### 1. 使用制限の中でも長く使いたい

Claudeにはどのプランにも使用制限があります。
この使用制限の単位は、5時間毎にかかる使用制限と週ごとにかかる使用制限があります。

そのため、プランや使い方次第では、なるべくトークンが少ない方法でClaudeを長く使いたいでしょう。

### 2. 常駐するトークンの量を減らして効率的に使いたい

Claude Codeには強制的に最初に消費されるトークンというものが存在します。
これらは新規に会話を始めたとしても必ず消費されるものです。

この常に消費されるものも減らすよう工夫することで、本当に行いたい作業に集中させることができます。
